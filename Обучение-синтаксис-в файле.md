## Шаг 1. Синтаксис внутри файла .md
Заголовки: 
Что такое заголовок? Заголовок — это крупный фрагмент текста в начале раздела. Существует шесть размеров заголовков.

Пример
```
# Это `<h1>` заголовок, самый крупный
## Это `<h2>` заголовок
###### Это `<h6>` заголовок, самый маленький
```
Как будет выглядеть в файле 
# Это `<h1>` заголовок, самый крупный
## Это `<h2>` заголовок
###### Это `<h6>` заголовок, самый маленький

## Шаг 2. Составьте список
Markdown поддерживает 3 типа распространенных списков. К ним относятся:

- Неупорядоченный — маркированный список
- Упорядоченный — нумерованный список
- Задача — список с флажками

#### Неупорядоченный список
Неупорядоченный список легко отобразить. Каждый элемент размещается на отдельной строке с помощью символов -, *, или +.
```
- Элемент 1
- Элемент 2
- Элемент 3
```
#### Упорядоченный список
Список изменяется на упорядоченный, если вместо символа списка используется любое число. Обратите внимание, как markdown автоматически обрабатывает подсчет. Приятно!
```
1. Шаг 1 
1. Шаг 2 
1. Шаг 3
```
#### Список задач
Список задач — это расширенный вариант неупорядоченного списка с использованием флажков.
Добавляйте пустые скобки [ ] для незавершенных задач и заполненные скобки [x] для выполненных задач. Примечание: для пустых скобок требуется свободное место.
```
[x] - Эта задача выполнена
- [ ] Эта задача не выполнена
```

## Шаг 4. Как добавлять ссылку 

В квадратных скобках напишите слово, которое будет выделено как ссылка и после в круглых скобках сама ссылка
```
Удали фон с изображения при помощи [CarvePhotos](https://carve.photos/)
```
#### Как это будет выглядеть:
Удали фон с изображения при помощи [CarvePhotos](https://carve.photos/)

## Шаг 5. Как добавлять изображение
#### Обычный Markdown
Изображения можно отобразить, указав относительный URL-адрес файла в репозитории или абсолютный URL-адрес (в любом месте в интернете).

Описательный текст в квадратных скобках отображается, если изображение не загружается, а также зачитывается вслух для людей, использующих программы чтения с экрана.

Примечание: в синтаксисе Markdown нет возможности изменить размер изображения.

#### Пример Относительный URL-адрес изображения в репозитории:
```
![Октокот Мона](myrepo/original.png)
``` 
#### Абсолютный URL-адрес изображения в интернете:
```
![Новогодняя елка]([https://octodex.github.com/images/original.png](https://ru.pinterest.com/pin/8514686791634900/))
```
#### Как это будет выглядеть:
Если не находит изображение:
![Октокот Мона](myrepo/original.png)

Если находит изображение
![Новогодняя елка](https://i.pinimg.com/1200x/00/57/22/005722fc2f51bdb749c62c40c3e4f840.jpg)

#### Простой HTML
Часто возникает необходимость уменьшить размер изображения или просто разместить его рядом с текстом. Обычный синтаксис HTML обеспечивает дополнительную гибкость.

В поле alt указывается альтернативный текст.
В поле src указывается исходный URL изображения.
Поля width и/или height можно использовать для указания размера в пикселях.
Поле align позволяет задать положение (left, right)
```
<img alt="Новогодняя елка" src="https://i.pinimg.com/1200x/00/57/22/005722fc2f51bdb749c62c40c3e4f840.jpg"
width="200" align="left">
```
#### Как это будет выглядеть:
<img alt="Новогодняя елка" src="https://i.pinimg.com/1200x/00/57/22/005722fc2f51bdb749c62c40c3e4f840.jpg"
width="200" align="left">
